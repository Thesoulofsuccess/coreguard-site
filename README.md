# Coreguard

Single-page lead-generation website for Coreguard, waterproofing and sealing specialists serving residential and commercial properties.

**Live:** https://www.coreguard.in

## Overview
- Goal: drive quote requests via phone contact
- Sections: hero, services ticker, Residential / Commercial, ethos (Diagnose, Chemistry, Precision), contact
- Stack: static HTML/CSS/JS, no build step
- Design: Modernist system, Cabinet Grotesk typography

## Deploy
Static site. Serve `index.html` from the repo root (Cloudflare Pages, Netlify, or GitHub Pages).
